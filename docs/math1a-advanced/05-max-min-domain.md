# 第5讲 最大・最小与定义域

本讲对应 **High Level 数学I 第4講 PART1～3**。

## 本讲课前回顾
对 (y=a$x-p$^2+q)，顶点是 ($p,q$)，轴是 $x=p$。有限区间上的最值必须同时看顶点与端点。

## 1 定义域移动时的最大最小
### 知识点
轴在区间内时，顶点可能给出最小/最大；轴在区间外时，比较端点与轴的远近。
### 解题技巧
先画数轴，标出**左端点、右端点、对称轴**，再分类。
:::info[High Level 讲义题]
对应 **第4講 PART1「2次関数の最大・最小」**。
:::
:::note[同类型练习]
对应 **PART1 確認問題**。
:::

## 2 二变量函数与四次函数的最大最小
### 知识点
有约束的二变量函数先消元；只含 $x^4,x^2$ 的四次函数令 $X=x^2$，但要补上 $X\ge0$。
### 解题技巧
**换元后一定重写定义域。**
:::info[High Level 讲义题]
对应 **第4講 PART2「2変数関数の最大・最小，4次関数の最大・最小」**。
:::
:::note[同类型练习]
对应 **PART2 確認問題**。
:::

## 3 二次函数的决定
### 知识点
已知顶点用标准形；已知两零点用因式形；已知三点用一般形。
### 解题技巧
先选让未知数最少的形式。
:::info[High Level 讲义题]
对应 **第4講 PART3「2次関数の決定」**。
:::
:::note[同类型练习]
对应 **PART3 確認問題**。
:::
