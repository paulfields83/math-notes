# 第7讲 解的配置・参数问题

本讲对应 **High Level 数学I 第6講 PART3、第7講 PART3**。

## 本讲课前回顾
判别式管“有没有根”，对称轴管“两根中心在哪”，(f$p$) 的符号管“点 $p$ 在两根内还是外”。

## 1 两根位于指定区间
### 知识点
只看 $D>0$ 不够，还要结合轴和端点函数值。
### 解题技巧
典型组合：**判别式 + 轴的位置 + 两端点符号**。
:::info[High Level 讲义题]
对应 **第6講 PART3「2次方程式の解の存在範囲」**。
:::
:::note[同类型练习]
对应 **PART3 確認問題**。
:::

## 2 两根分居某点两侧
### 解题技巧
开口向上且 $p$ 在两根之间时，直接看 (f$p$<0)。不要先写求根公式。

## 3 至少一个根在指定范围
### 知识点
允许“一个在内、另一个在外”和“两个都在内”。
### 解题技巧
结合端点函数值、顶点、判别式；必要时用补集。
:::info[High Level 讲义题]
对应 **第7講 PART3「2次方程式の解の存在範囲（少なくとも1つ）」**。
:::
:::note[同类型练习]
对应 **PART3 確認問題**。
:::
