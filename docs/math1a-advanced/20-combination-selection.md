# 第20讲 组合与选法

对应 **High Level 数学A 第3講 PART1～3**。

## 本讲课前回顾
[
{}_nC_r=\frac{n!}{r!(n-r)!},qquad
{}_nC_r={}_nC_{n-r}.
]

## 1 组合
有条件选择常用分类相加，或总数减去不满足条件。
:::info[High Level 讲义题]
对应 **第3講 PART1「組合せ」**。
:::
:::note[同类型练习]
对应 **PART1 確認問題**。
:::

## 2 含相同元素的排列
[
\frac{n!}{p!q!\cdots}.
]
### 解题技巧
先全部区分排列，再除掉相同元素内部交换的重复。
:::info[High Level 讲义题]
对应 **第3講 PART2「同じものを含む順列」**。
:::
:::note[同类型练习]
对应 **PART2 確認問題**。
:::

## 3 重复组合
[
{}_{n+r-1}C_r.
]
### 解题技巧
转成“(r) 个相同球放入 (n) 个盒子”，用隔板法。
:::info[High Level 讲义题]
对应 **第3講 PART3「重複組合せ」**。
:::
:::note[同类型练习]
对应 **PART3 確認問題**。
:::
