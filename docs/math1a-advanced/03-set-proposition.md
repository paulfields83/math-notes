# 第3讲 集合・命题综合

本讲对应 **High Level 数学I 第2講 PART1～3**。

## 集合・命题｜领域回顾
- 集合：元素、子集、空集、全集、补集。
- 集合运算：交集、并集、补集、德摩根律。
- 命题：条件、结论、真假。
- 充分条件、必要条件、必要充分条件。
- 逆、否、逆否。
- 直接证明、逆否证明、反证法。

完整概念见 **数学1A基础 → 第1章 集合与命题**。

## 本讲课前回顾
原命题 (p\Rightarrow q) 与逆否命题 (lnot q\Rightarrow lnot p) 同真同假。判断假命题时，一个反例就够。

## 1 命题与条件
### 知识点
(p\Rightarrow q) 表示满足条件 (p) 时，结论 (q) 必须成立。
### 解题技巧
真命题要说明“全部成立”；假命题只需找一个反例。
:::info[High Level 讲义题]
对应 **第2講 PART1「命題と条件」講義問題**。
:::
:::note[同类型练习]
对应 **PART1 確認問題**。
:::

## 2 充分条件与必要条件
### 知识点
若 (p\Rightarrow q)，则 (p) 是 (q) 的充分条件，(q) 是 (p) 的必要条件。
### 解题技巧
先画箭头，不要先背术语。双向都能推出时才是必要充分。
:::info[High Level 讲义题]
对应 **第2講 PART1** 中充分・必要条件问题。
:::

## 3 逆否证明
### 知识点
直接证明困难时，可以证明逆否。
### 解题技巧
先把结论准确否定，再从否定后的结论往回推。
:::info[High Level 讲义题]
对应 **第2講 PART2「命題と証明」講義問題**。
:::
:::note[同类型练习]
对应 **PART2 確認問題**。
:::

## 4 条件与命题的否定
### 知识点
否定时要把整个条件否掉。“所有”与“至少一个”也要一起改变。
### 解题技巧
常见对应：且↔或，(>)↔(le)，(=)↔(
e)。
:::info[High Level 讲义题]
对应 **第2講 PART3「条件の否定と命題の否定，必要条件から考える」講義問題**。
:::
:::note[同类型练习]
对应 **PART3 確認問題**。
:::

## 本讲整理
命题题先做：**写箭头 → 判断真假 → 必要时用逆否或反例。**
