# 第1讲 式的结构与高次变形

本讲不重新学习整式的基本运算，而是把重点放在：**看到复杂的式子以后，如何判断应该从哪里开始整理。**

> 本讲主线：**观察结构 → 选择主元 → 整理 → 降次 / 换元 → 再变形**

---

## 1. 多项式应该“关于谁”来看

含有多个字母的整式，不一定总要关于 (x) 整理。

例如一个含 (x,y) 的式子，可以：

- 看作关于 (x) 的多项式，此时 (y) 看作常数；
- 看作关于 (y) 的多项式，此时 (x) 看作常数。

### 进阶观察

遇到多字母因式分解时，优先比较：

1. 关于哪个字母的次数更低；
2. 关于哪个字母整理后结构更接近二次式；
3. 是否能出现公因式、完全平方或平方差。

:::tip[判断框架]
不要一上来全部展开。先问：

**“如果把其他字母当常数，关于哪个字母整理最简单？”**
:::

:::info[High Level 01｜选择主元]
**对应：高1・高2 ハイレベル数学I　第1講 PART1「因数分解」講義問題1**

重点不是计算速度，而是判断：

- 次数较低的字母优先；
- 两个字母次数相同时，比较哪一种整理更容易出现因式分解结构；
- 三个字母同时出现时，也可以任选一个字母作为主元重新观察。
:::

---

## 2. 因式分解不是“背公式”，而是寻找结构

基础公式仍然是：

[
A^2-B^2=(A-B)(A+B)
]

[
A^2+2AB+B^2=(A+B)^2
]

[
A^2-2AB+B^2=(A-B)^2
]

这里的 (A,B) 不一定只是一个字母，也可以是一整个式子。

### 常见观察顺序

**公因式 → 公式结构 → 按某个字母整理 → 把一部分看成整体 → 换元 → 人为构造结构**

:::warning[容易卡住的地方]
“看不出公式”时，不代表没有结构。

很多进阶题的关键恰恰是先重新整理，**让公式结构自己出现**。
:::

---

## 3. 高次式：先考虑能不能降次

如果一个四次式只含有

[
x^4,quad x^2,quad 常数
]

那么它实际上是关于 (x^2) 的二次式。

令

[
X=x^2
]

就可以把

[
ax^4+bx^2+c
]

转化为

[
aX^2+bX+c.
]

这类式子通常称为**复二次式**。

### 进阶观察

换元的目的不是“换一个字母”，而是：

> **把当前不会处理的高次结构，降低为熟悉的二次结构。**

换元之后如果仍然无法直接分解，还要继续检查能否构造

[
A^2-B^2.
]

:::info[High Level 02｜复二次式与平方差]
**对应：高1・高2 ハイレベル数学I　第1講 PART1「因数分解」講義問題1中的复二次式部分**

观察顺序：

**偶次幂 → (X=x^2) → 二次式 → 必要时构造平方差**
:::

## 4. 式的值：不要从目标式硬算

进阶的“式的值”问题，重点是找到：

> **已知式与目标式之间的代数关系。**

### 基本对称式

如果已知

[
x+rac1x=t,
]

那么平方后：

[
left(x+rac1xight)^2
=
x^2+2+rac1{x^2}.
]

所以：

[
x^2+rac1{x^2}=t^2-2.
]

进一步又可以利用低次结果得到更高次的

[
x^3+rac1{x^3},qquad
x^4+rac1{x^4}.
]

:::tip[核心思想]
不要直接计算高次式。

先问：

**“目标式能不能由已经知道的低次式经过平方、乘法或恒等变形得到？”**
:::

:::info[High Level 03｜基本对称式]
**对应：高1・高2 ハイレベル数学I　第1講 PART2「式の値」講義問題2[2]**

重点：由基本对称式逐步生成高次对称式。
:::

## 5. 二重根号与整数部分・小数部分

对于形如

[
sqrt{apm2sqrt b}
]

的式子，希望把它写成

[
sqrt mpmsqrt n.
]

平方比较后，需要满足：

[
m+n=a,qquad mn=b.
]

因此二重根号问题的核心，是寻找满足“和”与“积”条件的两个数。

### 整数部分与小数部分

若实数 (x) 的整数部分为 (a)，小数部分为 (b)，则

[
b=x-a,qquad 0le b<1.
]

所以在含根式的问题中，通常先把根式化简，再判断它落在哪两个相邻整数之间。

:::info[High Level 04｜二重根号]
**对应：高1・高2 ハイレベル数学I　第1講 PART2「式の値」講義問題2[1]**

关注两件事：

- 二重根号如何拆开；
- 化简后如何判断整数部分与小数部分。
:::

## 本讲整理

看到复杂代数式时，按下面的顺序观察：

**哪个字母最适合做主元？**

↓  

**有没有公因式或公式结构？**

↓  

**能不能把一部分看成整体？**

↓  

**高次式能不能降次？**

↓  

**目标式能不能由已知式变形得到？**
