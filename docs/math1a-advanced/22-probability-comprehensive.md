# 第22讲 概率综合演习

对应 **High Level 数学A 第4講 PART3、第5講 PART1・PART3**，并综合第4～5講确认问题。

## 本讲课前回顾
先分清：一次试验还是反复试验；是否独立；是否有条件；求概率还是期待值。

## 1 最大值・最小值的概率
### 解题技巧
优先求“最大值≤k”“最小值≥k”这类累计事件，再作差得到“恰好”。
:::info[High Level 讲义题]
对应 **第4講 PART3「最大値・最小値の確率」**。
:::
:::note[同类型练习]
对应 **PART3 確認問題**。
:::

## 3 期待值
$$
E(X)=\sum x_ip_i,\q\quad E(X+Y)=E(X)+E(Y).
$$
能拆成简单随机变量时，先分别求期待值再相加。
:::info[High Level 讲义题]
对应 **第5講 PART3「期待値」**。
:::
:::note[同类型练习]
对应 **PART3 確認問題**。
:::
