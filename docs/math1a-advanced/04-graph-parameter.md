# 第4讲 图像与参数

本讲对应 **High Level 数学I 第3講 PART1～3**。

## 二次函数｜领域回顾
- 一般形 $y=ax^2+bx+c$
- 标准形 $y=a(x-p)^2+q$
- 平方完成、顶点、对称轴
- 平移、对称移动
- 最大最小、方程、不等式、参数

完整概念见 **数学1A基础 → 第3章 二次函数**。

## 本讲课前回顾
平方完成后优先读出顶点和对称轴。图像题先看结构，不先展开计算。

## 1 一次函数的图像与最大最小
### 知识点
一次函数在闭区间上的最大最小值一定出现在端点。
### 解题技巧
$a>0$ 与 $a<0$ 时，最大最小所在端点相反。
:::info[High Level 讲义题]
对应 **第3講 PART1「1次関数のグラフと最大値，最小値」**。
:::

对应 **PART1 確認問題**。

## 2 抛物线的平移与对称移动
### 知识点
$y=f(x)$ 向右 $p$、向上 $q$ 平移得到 $y=f(x-p)+q$。
### 解题技巧
先追踪顶点，比展开式更快。

对应 **第3講 PART2「放物線の平行移動・対称移動」**。

## 3 二次函数系数与图像
### 知识点
$a$ 看开口，$c=f(0)$ 看纵截距，对称轴 $x=-\dfrac{b}{2a}$ 看 $b$ 与 $a$ 的关系。
### 解题技巧
固定顺序：**开口 → 截距 → 对称轴 → 参数符号**。
